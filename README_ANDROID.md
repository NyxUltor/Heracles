# Heracles Android

Native offline Android version of Heracles built with Kotlin and Jetpack Compose.

## What it includes
- Hamburger menu navigation
- Offline workout logger
- Local session saves in app storage
- Autosave draft on edits
- Session restore on launch
- Basic settings for units, default exercises, and restore behavior

## Open in Android Studio
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Run on a connected Android device or emulator.

## Build an APK
From Android Studio:
- Build > Build Bundle(s) / APK(s) > Build APK(s)

## Notes
- The app saves all data locally on the phone; no server is required.
- On a rooted J8, you can side-load the APK after building it.
